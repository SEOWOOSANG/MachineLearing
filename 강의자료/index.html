실습 준비

1. 파이썬 라이브러리 설치 (한 번만)

터미널(또는 주피터/Colab 셀)에서 다음을 실행합니다.

pip install pandas numpy matplotlib seaborn scipy statsmodels
2. 실습 데이터

data 폴더의 CSV 3개를 사용합니다.

파일내용원본 R 교재에서 대체한 데이터
tips.csv식당 계산서 244건 (금액·팁·성별·요일…)course (수강생 성적)
titanic.csv타이타닉 승객 891명Arthritis, BrokenMarriage
diamonds.csv다이아몬드 53,940개diamonds (동일)

코드는 이 HTML 파일들이 있는 폴더(강의자료)를 작업 폴더로 두고 실행한다고 가정합니다. 주피터 노트북을 이 폴더에서 열면 data/tips.csv 경로가 그대로 동작합니다.

한글이 깨져 보인다면?

각 장 첫 코드의 글꼴 설정(plt.rcParams['font.family'])을 그대로 실행하세요. Windows는 ‘맑은 고딕’, Mac은 ‘Apple SD Gothic Neo’를 사용하며, Google Colab에서는 나눔 글꼴 설치가 따로 필요합니다.
